От загрузки до игры.

Лаунчер подготовит Java и необходимые компоненты.

  1. 01

    Скачай EXE

    Сохрани Andromeda.exe на компьютере с Windows x64.

  2. 02

    Открой лаунчер

    Выбери учётную запись в настройках и нажми «Играть». Первый запуск загрузит нужные файлы.

    Сделай по-своему

ДЛЯ СВОЕЙ СБОРКИ / JAR

Тот же клиент. Твой лаунчер.

Отдельный мод 1.2.0 из актуальной сборки. Исправление служебных JSON работает в EXE-лаунчере.

  1. 01

    Подготовь Fabric

    Minecraft 1.21.11, Java 21 и Fabric Loader 0.19.5 или новее.

  2. 02

    Добавь Fabric API

    Нужен Fabric API 0.141.6+1.21.11 или новее для Minecraft 1.21.11.

  3. 03

    Положи JAR в mods

    Замени прежний файл Andromeda на andromeda-1.2.0.jar в папке mods выбранной сборки. Запусти её через Fabric.
